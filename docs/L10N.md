# Localization (ru / kk)

The app is in Russian and Kazakh. Russian (`app_ru.arb`) is the source; the
Kazakh texts (`app_kk.arb`) are **machine translations** and every one of
them needs a review by a native speaker before a real release.

## How it works

- `flutter_localizations` + gen-l10n: `apps/mobile/lib/l10n/app_ru.arb`,
  `app_kk.arb` → `lib/l10n/gen/` (generated, committed, formatted).
- Every visible string goes through `AppLocalizations` (`context.l10n`). The
  design kit has no texts of its own: labels are parameters. CI fails on a
  Cyrillic literal in `apps/mobile/lib` or `packages/design_kit/lib` outside
  the generated code (comments excepted).
- Plurals are ICU: ru one / few / many / other, kk one / other
  (`tripsCount`).
- Dates use `intl` with the active locale: ru «1 октября 2026», kk
  «2026 ж. 1 қазан» (CLDR, with a no-break space before «ж.»), short admin
  dates «9 окт., 22:34» / «9 қаз., 22:34». Today / yesterday: Сегодня /
  Бүгін, Вчера / Кеше.
- Money is the same in both languages: `1 815 ₸` (U+202F, `₸`). Screen
  readers say «1 815 тенге» / «1 815 теңге» (`moneySpoken`).
- Server errors are shown by error code and field, never the server's own
  message.
- The language is chosen on the login screen and in the menu
  (`DkLanguageSwitch`, «Русский» / «Қазақша», each in its own language),
  applies at once and is kept in `shared_preferences`. Without a saved
  choice: the phone's language if it is Russian or Kazakh, else Russian.

## Not translated

- Data from the server: display names («Водитель 1»), reject reasons typed
  by the admin. They are shown as stored.
- Language names (always in their own language).
